# Primer design-system update log

## 2026-08-24
* **Update**: Migrated to ODSF v0.2 / OKF v0.2. Container: `timestamp` became `generated: { by, at }` across all 60 concepts, six `# Citations` sections became `sources` frontmatter (10 entries), and the root `index.md` now declares `odsf_version: "0.2"` / `okf_version: "0.2"`. Structure layer: added `styles/wireframe.css` and derived a `*.wireframe.html` for 44 of the 45 components plus the repo-page pattern, each carrying its example's `<body>` verbatim with the skin stripper linked last; wrote a `# Structure` section into all 45, declared the wireframes in `examples` frontmatter and the `# Examples` lists. Only `label` got none, its example being a row of leaf pills with no internal nesting. The structural notes record several rules that are load-bearing and easy to drop when copying: `min-width: 0` on both `PageLayout` tracks, the reserved right padding that keeps a select's option text off its painted chevron, and the `14px` timeline rail offset that must move with the badge size.

## 2026-06-23
* **Update**: Expanded the component set from 22 to **45** — added button-group, textarea, autocomplete, token, select-panel, action-menu, dialog, popover, nav-list, tree-view, tab-nav, header, footer, page-layout, page-header, data-table, timeline, details, truncate, branch-name, avatar-stack, circle-badge, and skeleton (each with a runnable example), plus the supporting CSS. * **Creation**: Initial Primer (GitHub) bundle for ODSF v0.1. Tokens read directly from the live primer.style DOM (`@primer/primitives`) in both light and dark modes — the bundle ships Primer's own variable names (`--fgColor-default`, `--button-primary-bgColor-rest`, …) so generated code matches real Primer. Includes foundations (color, typography, spacing, elevation, shape, motion, layout), 22 components with runnable examples across actions (button — shown light+dark, icon-button, link), forms (text-input, select, checkbox, radio, toggle-switch, segmented-control), status & feedback (label, state-label, banner, spinner, progress-bar, tooltip), navigation (underline-nav, breadcrumbs, pagination, action-list), and content (box, avatar, blankslate); the repository-page pattern, color-modes and focus behaviors, two guidelines with counter-examples (use-functional-tokens, color-not-alone), two references, and `styles/tokens.css` (light + dark + auto) plus `styles/components.css`.
